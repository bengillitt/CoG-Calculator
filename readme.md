# A centre of gravity calculator to help you with further maths problems

## How to Install

- Pull git project
- run 'cargo run'

# How to Use

- Enter Number of shapes
- Enter shape type for each shape
- Enter key points of the shape and data such as mass, density and area

# Why?

- A simple project to make in order to help me learn rust (I plan on making something much bigger with rust...)
- Can help with further maths problems
